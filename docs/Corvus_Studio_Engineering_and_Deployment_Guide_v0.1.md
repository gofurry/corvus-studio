# Corvus Studio Engineering & Deployment Guide v0.1

## 1. 工程原则

目标：

-   可维护
-   跨平台
-   本地优先
-   开源友好

------------------------------------------------------------------------

## 2. 工程结构

采用 Monorepo：

包含：

-   Go Core
-   React Frontend
-   Fyne Launcher
-   Agent
-   Documentation
-   Deployment

------------------------------------------------------------------------

## 3. 构建

Go：

单二进制。

React：

Vite Build 后由 Go 提供。

Fyne：

仅负责 Launcher。

------------------------------------------------------------------------

## 4. CI/CD

使用 GitHub Actions。

PR 检查：

Backend：

-   go test
-   golangci-lint

Frontend：

-   lint
-   test
-   build

------------------------------------------------------------------------

## 5. 发布

Semantic Versioning。

支持：

-   Windows
-   macOS
-   Linux
-   Docker

------------------------------------------------------------------------

## 6. 部署

Docker：

使用挂载目录保存用户数据。

Systemd：

支持非 root 运行。

------------------------------------------------------------------------

## 7. 数据迁移

使用 goose。

升级流程：

检测版本 → 备份 → Migration → 启动。

------------------------------------------------------------------------

## 8. 日志与诊断

技术：

-   zap
-   lumberjack

提供：

corvus doctor

用于检查：

-   数据库
-   配置
-   模型连接
-   文件权限

------------------------------------------------------------------------

## 9. 更新策略

v0.1：

不自动更新。

用户手动升级。

------------------------------------------------------------------------

## 10. 开源流程

Issue → Discussion → PR → CI → Review → Merge
