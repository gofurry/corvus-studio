# Corvus Studio 文档导航

本目录按文档职责分类。实现工作应先确认所属阶段，再按下列优先级解决冲突：

1. `development/` 中的开发实施计划决定阶段范围和边界；
2. `architecture/` 中的仓库结构设计决定 Monorepo 结构；
3. `architecture/` 中的技术栈决策决定已确认选型；
4. `deployment/` 中的工程与部署指南决定构建、CI 和跨平台要求；
5. 根目录 `USAGE.md` 决定目标开发命令和开发者体验；
6. 其余文档提供产品、接口和后续阶段背景，不得据此提前实现未来阶段。
